# Getting help with Pico

| You want to… | Go here |
|--------------|---------|
| Set Pico up, or fix a setup problem | The [setup guide](docs/CUSTOMER-SETUP-GUIDE.md) — its troubleshooting section covers most questions |
| Report a bug | [Open a bug report](https://github.com/CloudpiAi/Pico/issues/new?template=bug-report.yml) |
| Suggest a feature | [Open a feature request](https://github.com/CloudpiAi/Pico/issues/new?template=feature-request.yml) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/CloudpiAi/Pico/discussions) |
| Report a security problem | **Not an issue** — follow [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct problem | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before you open an issue, please search the existing issues and remove anything private from logs and screenshots: AWS account IDs, bucket names, Slack tokens and API keys.

Pico is maintained by a small team. We try to answer new issues within a week; there is no guaranteed response time.
